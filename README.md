# Eglandin® Liver Transplant Dose Calculator

타나베파마코리아 내부 직원이 간이식 후 알프로스타딜 기준 용량과 에글란딘 2 mL 앰플 상당량을 빠르게 환산하기 위한 정적 웹 도구입니다.

이 도구는 정해진 기준의 **수학적 환산**만 수행합니다. 권장 처방량, 실제 투여량 또는 실제 개봉·조제 앰플 수를 결정하지 않습니다. 환자 입력값은 브라우저 밖으로 전송하거나 저장하지 않습니다.

## 계산 기준

프로젝트 요구사항으로 제공된 아래 기준을 고정값으로 사용합니다.

| 항목 | 값 |
| --- | ---: |
| 알프로스타딜 기준 용량 | 0.6 μg/kg/hr |
| 1일 | 24 hr |
| 에글란딘 1앰플 | 2 mL, 알프로스타딜 10 μg |
| ABO 적합 간이식 | 최대 7일 |
| ABO 부적합 간이식 | 최대 14일 |

```text
hourlyDose = weightKg × 0.6
dailyDose = hourlyDose × 24
ampsPerDay = dailyDose ÷ 10
```

ABO 유형은 최대 기준 투여기간에만 영향을 주며 용량 환산에는 영향을 주지 않습니다. 앰플 상당량은 내부 계산값을 유지한 뒤 표시 단계에서만 소수 첫째 자리로 반올림하며, 정수 앰플 수로 올림하지 않습니다.

## 근거 문서 확인사항

- 첨부된 식품의약품안전처 제품정보에서 에글란딘주의 허가 효능·효과 및 용법·용량을 확인했습니다.
- 첨부된 「요양급여의 적용기준 및 방법에 관한 세부사항과 심사지침」에는 `Alprostadil 주사제(품명: 에글란딘주 등)`를 허가사항 용법·용량 범위를 초과하여 간이식에 투여한 경우 요양급여를 인정한다고 기재되어 있습니다(고시 제2021-294호).
- 위 첨부 문서에는 이 계산기에 사용한 `0.6 μg/kg/hr`, `ABO 적합 7일`, `ABO 부적합 14일`의 세부 수치가 직접 기재되어 있지 않습니다. 따라서 이 수치들은 프로젝트에서 제공된 환산 기준으로 관리하며, 공식 기관이 개발·보증한 계산기 또는 임상 권고로 표현해서는 안 됩니다.
- 「허가 또는 신고범위 초과 약제 비급여 사용승인에 관한 기준 및 절차」는 별도의 제도 절차 문서이며 본 계산 로직의 수치 근거로 사용하지 않습니다.

## 입력 검증

- 빈 값, 문자, 지수 표기, 복수 소수점, 0 이하, `Infinity`, `NaN`을 거부합니다.
- 소수점 체중을 허용합니다.
- 실수 입력 방지를 위한 운영상 상한은 300 kg입니다. 이는 임상적 허용 체중 또는 의학적 판단 기준을 의미하지 않습니다.
- 입력이나 ABO 유형이 변경되면 이전 계산 결과를 즉시 숨깁니다.

## 로컬 실행 및 테스트

외부 dependency와 빌드 과정이 없습니다. `index.html`을 정적 서버로 제공하면 됩니다.

```bash
npm test
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 유지보수

기준 변경 시 `dist/calc.js`의 `CALCULATION_CONSTANTS`를 수정합니다.

- `DOSE_LIMIT_MCG_PER_KG_HR`: 시간당 체중 기준 용량
- `HOURS_PER_DAY`: 1일 시간
- `AMP_MCG`: 앰플당 알프로스타딜 함량
- `MAX_DAYS`: ABO 유형별 최대 기간
- `MAX_WEIGHT_KG`: 운영상 입력 상한

변경 후 `npm test`를 실행하고, `tests/calc.test.js`의 기준값과 근거 문서 확인사항을 함께 갱신해야 합니다.
